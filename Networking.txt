    Networking command

1. System Metadata (OS, Kernel, Architecture)
uname -a           # Full system info (kernel, architecture, etc.)
cat /etc/os-release  # Linux distribution info (Ubuntu, Debian, etc.)
hostnamectl        # Hostname + OS + kernel + architecture
lsb_release -a     # Ubuntu/Debian release info

              2. Hardware Metadata
lscpu              # CPU details
lsmem              # Memory block info
free -h            # Memory usage summary
lshw -short        # Hardware summary (need sudo)
lsblk              # Block devices (disks, partitions)
df -h              # Mounted filesystem info
 3. Network Metadata
ip a               # All network interfaces + IPs
ip route           # Routing table
hostname -I        # All IP addresses
cat /etc/hosts     # Local host mappings
nmcli device show  # Detailed network info (NetworkManager)


🧩 4. Process / Runtime Metadata
ps aux             # All running processes
top                # Live process monitor
env                # Environment variables
whoami             # Current user
id                 # UID/GID and groups
   
          For AWS EC2:
    curl -s http://169.254.169.254/latest/meta-data/
        
          User & System Metadata
who                # Logged-in users
uptime             # How long system has been running
last               # Login history
w                  # Logged-in users and what they’re doing
